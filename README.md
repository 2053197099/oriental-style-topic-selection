# 东方风格选题

**为东方角色与场景创作寻找题材：先比较候选，再建立简短世界观，最后得到可继续设计的角色与场景清单。**

你可以从一句需求、一张作品图或现有媒体作品开始，不需要先准备完整世界观，也不需要会写提示词。

**创作目标 / 参考素材 → 2–3 个候选 → 你选择 → 简短世界观 + 十个角色 + 十个配套场景**

## 能做什么

| 功能 | 你会得到什么 |
| --- | --- |
| 没有题材，寻找灵感 | 有区别的东方题材候选、参考依据及少量角色或场景示例 |
| 根据作品图选题 | 结合整张图的颜色关系、光影、材质笔触、造型、构图与情绪，推荐适合的方向 |
| 参考现有媒体 | 从影视、动画、漫画、游戏、小说，以及抖音、小红书等自媒体内容中提炼题材 |
| 建立世界观 | 一段解释生命构成、生活或生存方式、相互关系及共同视觉特征的简短设定 |
| 展开角色 | 人类、神祇、山海妖兽、植物灵、器物生命、拟人生物或其他非人形生命 |
| 配套场景 | 符合角色尺度、生存方式与世界设定的地点，默认十个 |
| 继续调整 | 沿用已有设定，补充、重写或只交付指定的角色、场景部分 |

题材需要具有东方文化、美学或叙事依据，**不局限于古装、武侠、仙侠，也不受固定的 26 类题材限制**。[题材参考库](references/oriental-genres.md)只是可选的灵感来源。

## 三步开始

### 1. 提出需求

安装 Skill 后，在 Codex 中输入：

```text
使用 $oriental-style-topic-selection。
我想做一组东方志怪角色，给我几个有差异的选题。
可以包含山海妖兽、器物精怪和拟人生物。
```

也可以附上作品图，或指定希望参考的媒体作品。没有图片也能开始。

### 2. 比较并选择

Skill 默认推荐 **2–3 个候选**，说明主题、角色或场景示例及推荐依据。

你可以回复候选编号，例如：

```text
选 2。
```

不满意时直接说出原因，例如“太常见”“不要全是人类职业”“更想做自然妖兽”。

“帮我想一个题材”仍会先给候选供比较；明确说“只给一个，不要备选”时才只推荐一个，并等待你选定。已经明确题材时，直接进入交付，不重复选题。

### 3. 获得创作清单

选定后默认一次交付：

- 一个选题标题。
- 一段简短世界观。
- 十个角色，每项包含名称与一句精简描述。
- 十个配套场景，每项包含名称与一句精简描述。

即使最初只说“想做东方角色”，选定后也默认附上世界观和配套场景。数量与范围可以明确指定，例如“只要六个角色，不要场景”或“只做场景”。

## 可直接复制的用法

**根据作品图找题材**：先附作品图，再输入：

```text
根据这组作品图推荐几个东方题材。
分析整体风格，角色种类拉开差异，等我选择后再展开。
```

提供的应是可分析的作品画面；只有项目列表、控件或参数标签的截图不能代替作品图。

**参考影视、游戏或自媒体内容**：

```text
我想做东方奇异生物，参考现有动画、游戏或小说给我几个题材。
请说明具体借鉴了哪些元素，并区分原作品内容与创作延伸。
```

也可以指定作品、账号内容或提供链接。普通灵感推荐可以使用可靠的已知内容；要求近期热门内容或平台趋势时，按需核实并标明来源。实际检索、链接读取能力以使用环境为准，无法读取时会如实说明。

**已经确定题材，直接展开**：

```text
题材已确定为“画壁漏妖”。
建立简短世界观，给我十个角色和十个匹配场景，每项加精简描述。
```

**补充人形态角色**：

```text
沿用这个世界观，再给我一组人形态角色。
以拟人生物为主，保留动物、植物或器物的本体特征，不限定人类。
```

“人形态”包含具有类人轮廓或拟人姿态的生命，不等于只要人类。明确要求人类、纯自然妖兽或单一物种时，会按你的范围展开。

**重写某一部分**：

```text
只重写场景，保留现有角色和世界观。
空间结构与用途要有区别，每项附一句精简描述。
```

## 输出长什么样

固定顺序为：**标题 → 世界观 → 角色方向 → 场景方向**。

下面仅展示格式节选，实际默认角色与场景各十个：

**画壁漏妖**

**世界观**

古寺残画中的异物逐渐进入现实。它们保留着墨痕、纸绢与朱砂残印，依靠矿彩和旧画碎片维持生命。有的寻找残片修补身体，有的希望摆脱原来的画中身份。

角色方向

```text
空胸藏卷道人：卷纸折成瘦长人形，空胸藏着层叠残页。
朱印独目祟：方印构成头颅，独眼嵌在印面中央，双臂由墨线垂成。
```

场景方向

```text
山崖悬空画寺：寺院半嵌绝壁，断裂画廊伸向云海。
墨染山溪：溪水穿过剥落画壁，岸边草木逐渐显出水墨纹路。
```

标题、世界观和标签在代码块外；角色与场景分别使用独立代码块，**每行一项“名称：精简描述”**，不加序号、项目符号或空行。描述补充具体的形态、身份、习性、空间或用途，不扩成长篇设定。明确只要名称时，可以省略描述。

## 如何安装与调用

在支持本地 Skill 的 Codex 环境中，将仓库内容放入该环境配置的技能目录。例如，使用项目内的技能目录时，结构如下：

```text
.agents/skills/oriental-style-topic-selection/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── oriental-genres.md
```

首次安装可在项目根目录执行：

```bash
mkdir -p .agents/skills
git clone https://github.com/2053197099/oriental-style-topic-selection.git .agents/skills/oriental-style-topic-selection
```

在新的 Codex 会话中使用 `$oriental-style-topic-selection`，并描述需求或提供素材。若环境配置了其他技能目录，请按该环境的配置安装；已有安装应保持与仓库版本同步。

## 如何继续生成提示词

本 Skill 负责选题、简短世界观和角色与场景方向，**不生成 Midjourney 提示词或图片**。

选定后，你可以把世界观和清单复制给：

- [东方角色提示词 Skill](https://github.com/2053197099/midjourney-oriental-game-characters)：继续设计角色提示词。
- [东方场景提示词 Skill](https://github.com/2053197099/midjourney-wuxia-environments)：继续设计场景提示词。

不会自动向其他聊天发送消息。普通创作也不会修改 Skill 文件或执行 Git 操作。

## 在东方图库流程中的位置

| 你现在要做什么 | 使用的 Skill | 得到什么 |
| --- | --- | --- |
| 还没确定题材，先找方向 | [东方风格选题](https://github.com/2053197099/oriental-style-topic-selection) | 候选题材；选定后给出简短世界观、角色与场景方向 |
| 已有题材，要设计角色 | [东方题材角色](https://github.com/2053197099/midjourney-oriental-game-characters) | 原创角色的中英文 Midjourney 提示词 |
| 已有题材，要设计环境 | [东方题材场景](https://github.com/2053197099/midjourney-wuxia-environments) | 纯环境场景的中英文 Midjourney 提示词 |
| 已有筛选好的原图和提示词 | [图文作品排版](https://github.com/2053197099/image-prompt-layout) | 每张原图一张上图下文 PNG，以及图片与提示词配对清单 |

四个 Skill 可以单独使用，不必从选题开始。角色与场景 Skill 的交付是提示词文本；实际出图需在你使用的图像生成工具中完成。跨聊天继续时，请主动复制已确认的世界观、方向或提示词，并上传对应原图与清单；共用环境不表示任务素材自动共享。飞书整理需另行授权与连接，这四个 Skill 不会自动访问飞书或向其他聊天发消息。
