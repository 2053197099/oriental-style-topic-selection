# 东方风格选题

角色与场景提示词设计之前的 Codex Skill：根据影视、动画、漫画、游戏、小说等作品，抖音、小红书等自媒体内容，或用户提供的风格素材提供东方题材思路，无需先有参考图，题材不限于固定目录。用户选定后建立简短世界观，并输出角色与配套场景方向。

## 使用流程

1. 提出创作目标、指定媒体作品或提供风格素材，获得 2–3 个有差异的候选及参考依据。“想一个题材”仍先给候选供比较；明确“只给一个，不要备选”时才只给一个。
2. 选择一个方向，或提出调整意见。
3. 确定后按“标题 → 世界观 → 角色方向 → 场景方向”交付。世界观是一段简短正文，角色与场景默认各十个，分别用独立代码块，每行一个方向，不加序号、项目符号或空行。

角色题材默认也附上十个符合世界观的场景。角色身份、社会关系和场景用途应互相支持；场景不必与角色一一对应，应包含不同空间或地点功能。用户明确排除某部分或指定数量时，以其要求为准。已有角色或世界观会直接沿用，不重新选题或替换角色。

例如：“我需要做一些东方角色，根据现有媒体帮我想一个题材。”Skill 会选择合适的影视、动画、漫画、游戏、小说或抖音、小红书等自媒体内容作为参考，给出 2–3 个具体主题、借鉴元素、角色示例及推荐原因，等待用户选择。选择后一次给出简短世界观、十个角色和十个配套场景。此例是调用方式，不是已确认的创作任务。用户提供作品图时仍会分析整张图的风格。

自媒体参考需要具体内容依据，不能只报平台名称或编造帖子与热度。普通推荐可用可靠的已知内容；请求近期热门内容或平台趋势时，按需核实并标明来源。

本项目负责选题、确认、简短世界观及角色与场景方向，不生成提示词。角色提示词交给 [角色 Skill](https://github.com/2053197099/midjourney-oriental-game-characters)，场景提示词交给 `midjourney-wuxia-environments`；用户自行复制世界观与方向到对应聊天。

## 角色与生命多样性

“角色”包括人物、山海妖兽、植物或器物之灵、群体生命与非人形奇异生物。开放的东方幻想选题，在适合风格和目标时，应提供以非人生命为主体的候选；明确要妖兽或奇特生物时，围绕生物构建整组候选。

选定后从身体结构、轮廓、尺度、材质、栖息方式及生态或社会功能中建立真实差异，并解释角色之间的共生、竞争、迁徙、契约等关系。场景随生命形态与尺度推导，不全是人类城镇和工坊。纯人类、写实或单一物种限制按用户要求处理，不强制混入其他生命或套固定比例。

## 世界观构建方法

先选定一条真正影响生存或生活的规则，再从环境与资源推导角色的形态、行为及相互关系，并据此安排场景。非人生命的结构与能力应有用途及边界；角色或群体的区别应来自不同处境与选择。场景揭示不同生活或生态功能，已确定的世界规则、尺度与资源关系保持一致。

这些是内部构建方法，交付仍为一段简短世界观及角色、场景方向，不默认增加问卷、关系图、设定表、提示词或摄影参数。

## 本地使用

将 `SKILL.md`、`agents/` 和 `references/` 放入 `~/.codex/skills/oriental-style-topic-selection/`，随后在新聊天中使用 `$oriental-style-topic-selection` 并描述创作目标或提供参考素材。仓库维护源与本地安装副本应保持一致。

## 验证

有 `skill-creator` 时可使用其 `scripts/quick_validate.py` 检查 Skill 元数据，并检查相对引用、题材参考库及安装副本一致性。维护时检查以下行为；结构校验不代表选题审美判断已经验收。

| 输入情形 | 预期行为 |
| --- | --- |
| 无图请求“帮我想一个东方角色题材” | 给 2–3 个有真实媒体依据且有差异的候选，等待选择 |
| 明确“只给一个，不要备选” | 给一个推荐，仍等待用户实际选定 |
| 提供作品图 | 从整体风格提炼依据，默认给 2–3 个候选 |
| 回复最近候选的编号 | 承接选题，输出标题、世界观、十个角色及十个匹配场景 |
| 初始需求只提“东方角色” | 选定后仍默认附上世界观与十个配套场景 |
| 明确“只要角色，不要场景”或“只做场景” | 按明确范围交付世界观与对应方向 |
| 已有角色，补要世界观及场景 | 保留已确定角色，补全相容设定与十个场景，不重开选题 |
| 要求抖音、小红书近期热门内容 | 按需核实具体内容并标明来源，不编造帖子、账号或热度 |
| 开放的东方幻想题材，未限定角色物种 | 适合时至少一个候选以非人生命为主体，不全是人类职业 |
| 明确要山海妖兽、奇特生物 | 整组候选以生物为主体，形态、体量与生态关系有区别 |
| 反馈世界观角色太单一 | 检查生命构成与相互关系，不只增加职业或兽耳人形 |
| 已选非人形生物题材 | 给出有辨识度的生物方向与匹配其尺度、栖息和生命周期的场景 |
| 限定纯人类、写实或单一物种 | 在限定范围内建立多样性，不强制加入其他生命 |
| 有奇异器官或特殊能力的生物 | 结构与行为相联，能力来源、边界或代价符合世界规则 |
| 同批场景重复宏大奇观或同类工坊 | 从生存、日常、迁徙、资源或关系中补足不同用途，不强填类别 |
| 新设定与旧世界规则冲突 | 保留已有事实，明确冲突，不用传说或未知遮掩 |
| 借鉴外部世界观方法 | 仅消化适用方法，不将外部全文或压缩包作为运行时参考依赖 |
